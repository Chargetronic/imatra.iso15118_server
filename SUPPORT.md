# Getting help

## Where to ask

| For | Where |
|---|---|
| Questions ("how do I…"), ideas | [GitHub Discussions](https://github.com/chargetronic/imatra.iso15118_server/discussions) (opens with the public release) |
| Bugs and feature requests | [issue tracker](https://github.com/chargetronic/imatra.iso15118_server/issues), with the templates |
| Security vulnerabilities | **not** in public: [SECURITY.md](SECURITY.md) |
| Code of Conduct concerns | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Anything else | the project lead, cto@chargetronic.fi |

Further community channels, if opened, will be listed here.

## Reporting a bug

Use the bug template. Say which version or commit you run, how many engines,
`PKI_MODE`, what the device and the vehicle did (ISO 15118-2, DIN 70121 or
PWM), what you expected and what happened, and attach the relevant log lines
of the engine and the API with secrets removed. A reproduction with `fleetgen`
helps most.
